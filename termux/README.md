# VibeCoding in Termux

You need nodejs and git at least:

```bash
pkg update -y && pkg upgrade -y
pkg install -y nodejs-lts git
```

Related fixes are in here: https://github.com/DioNanos/pty-termux-utils

## Codex

Source: https://github.com/DioNanos/codex-termux

```bash
npm install -g @mmmbuto/codex-cli-termux
npm install -g @mmmbuto/codex-cli-lts
```

## QwenCode

Source: https://github.com/DioNanos/qwen-code-termux

```bash
npm install -g @mmmbuto/qwen-code-termux@latest
```

## Gemini
